# INVOLUCRADOS · Entre jugadores y creadores

Línea de tiempo interactiva de la industria de videojuegos en Colombia (2002–2026), contada como un juego de terminal retro.  
Proyecto de grado · Diseño Gráfico · Universidad Antonio Nariño — Juan Manuel España Franco.

## Jugar

Abre la página publicada con GitHub Pages o, en local, abre `index.html` en Chrome o Edge.  
La música y los sonidos empiezan después del primer clic o tecla, porque el navegador bloquea el audio automático.

## Controles

- **Flechas y ENTER:** navegar por menús y carpetas.
- **ESC:** volver atrás o salir al selector de niveles.
- **Mantener ESPACIO:** acelerar el texto.
- **TAB en el selector:** abrir el reporte del archivo de evidencias.
- **R (registro 06):** usar un enlace oculto ◈ para restaurar un fragmento.
- **F2:** curvatura CRT de alta calidad (exige más al computador).

## Archivos

| Archivo | Uso |
|---|---|
| `index.html` | El juego completo, con imágenes, fuentes y algunos audios incluidos |
| `INICIO_FONDO.mp4` | Video de fondo de la pantalla de inicio |
| `SELECTOR_FONDO.mp4` | Video de fondo del selector de niveles |
| `CLICK_INICIAR.mp3` | Clic al iniciar o entrar a un nivel |
| `TECLA.mp3` | Sonido de cada tecla |
| `ERROR.mp3` | Sonido de error |
| `CARGA.mp3` | Barras de carga |
| `MUSICA_INICIO.mp3` | Música de la pantalla de inicio |
| `FAX.mp3` | Imágenes que llegan como fax |
| `TENSION.mp3` | Música de tensión del registro 06 |

Los nombres distinguen mayúsculas y minúsculas: deben quedar exactamente así.
